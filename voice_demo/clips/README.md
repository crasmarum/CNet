# Demo clip

`clip2_noisy.wav` is a seven-second noisy recording from the test set of VoiceBank-DEMAND (Valentini-Botinhao et
al., 2016, University of Edinburgh DataShare, licence CC BY 4.0), resampled to 16 kHz mono. The demo models never
saw this speaker or this noise during training. `play_demo.sh` writes `clip2_enhanced.wav` next to it.
